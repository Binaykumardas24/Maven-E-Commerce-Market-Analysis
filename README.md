# Maven-E-Commerce-Market-Analysis
# 🛒 Maven Market Retail Analytics Dashboard | Power BI

## 📌 Project Overview

The **Maven Market Retail Analytics Dashboard** is an interactive Power BI project designed to analyze retail sales performance, profitability, transactions, and product returns.

The dashboard provides insights into product brands, store locations, country-wise transactions, weekly revenue trends, and financial performance against targets.

This project demonstrates how data analytics and interactive visualizations can help businesses monitor performance and identify opportunities for improvement.

## 🎯 Project Objectives

- Monitor retail transactions, revenue, profit, and product returns.
- Analyze product brand performance and profitability.
- Compare transaction performance across different countries and store locations.
- Track weekly revenue trends and identify changes in performance.
- Compare actual performance against business targets.
- Develop interactive dashboards to support data-driven decisions.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Interactive dashboard development and visualization
- **DAX** — KPI calculations and performance measures
- **Power Query** — Data cleaning and transformation
- **CSV Files** — Data sources

## 📊 Dashboard Highlights

### 1. Key Performance Indicators (KPIs)

The dashboard displays important retail performance metrics:

- **Total Transactions:** 18,325
- **Total Profit:** $71,682
- **Total Returns:** 496
- **Total Revenue:** $120,161

These values represent the totals displayed in the dashboard, while the top KPI cards show current-month performance.

### 2. Product Brand Analysis

- Compared product brands based on transaction volume and total profit.
- Analyzed profit margins across different brands.
- Examined product return rates to understand return patterns.
- Used conditional formatting to make brand performance easier to compare.

### 3. Geographic Analysis

- Analyzed transactions across the USA, Mexico, and Canada.
- Visualized store locations using a geographic map.
- Compared transaction volumes and financial performance across countries.

### 4. Revenue Trend Analysis

- Created a weekly revenue trend visualization.
- Compared revenue fluctuations over time.
- Highlighted revenue peaks and changes in weekly performance.

### 5. Target Performance Analysis

- Compared revenue performance against business targets.
- Displayed current-month transactions, profit, and returns alongside their respective goals.
- Added a date filter to explore performance for different periods.

## 🔍 Key Insights

- The USA accounts for approximately **51% of transactions**, followed by Mexico at 40% and Canada at 9%.
- Total profit is approximately **$71.7K**, based on the dashboard's displayed figures.
- The dashboard records **18,325 transactions** and **496 returns** in the displayed reporting period.
- Product brands show varying profit margins and return rates, allowing users to compare their performance.
- Weekly revenue fluctuates over time, making trend analysis useful for monitoring retail performance.

## 🚀 How to Run the Project

1. Clone or download this GitHub repository.
2. Install Microsoft Power BI Desktop.
3. Open `Maven Market Dashboard.pbix`.
4. If Power BI cannot locate the source files, update the data source paths to match your local CSV files.
5. Refresh the data if required.
6. Explore the dashboard using the date filter, charts, tables, and other interactive elements.
